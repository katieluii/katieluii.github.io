# KRAS Class Trajectory — Deep Thematic Synthesis
**Theme:** `kras_class_trajectory`
**Date:** 2026-06-05
**Scope:** KRAS G12C / G12D / pan-RAS inhibition across NSCLC, CRC, PDAC

---

## 1. Thesis Summary

KRAS inhibition has moved from proof-of-concept (sotorasib, NSCLC, 2021) to a multi-indication, multi-allele competitive field in five years. The class is bifurcating: G12C-selective agents (sotorasib, adagrasib) are entering combination and label-expansion wars driven by resistance data, while next-generation multi-mutant and pan-RAS agents (RMC-6236 / daraxonrasib) are targeting the larger G12D and wild-type-sparing opportunity primarily in PDAC and broad-solid-tumour settings. The critical 2025-2026 inflection is whether pan-RAS can thread the therapeutic window that G12C agents inherently avoided — and whether combinations can rescue single-agent G12C activity in notoriously resistant histologies (CRC, PDAC).

## 3. CRC — G12C Combos Required, But Bar Is Higher

### 3a. CodeBreaK 300 — Sotorasib + Panitumumab (Amgen)
| Parameter | Data |
|---|---|
| Trial | NCT05198934 — Phase 3, sotorasib 960 mg + panitumumab vs investigator's choice (TAS-102 or regorafenib), 3L+ CRC G12C |
| Published result (NEJM 2023) | mPFS: soto 960+pani 5.6 mo vs control 2.2 mo; HR 0.49 (p<0.001); ORR 26.4% |
| 240 mg arm | mPFS 3.9 mo (inferior to 960 mg arm, confirms dose-dependency) |
| OS | Immature at primary analysis; update expected 2025-2026 conference cycle |
| Regulatory | Breakthrough therapy designation; BLA under review; full FDA decision expected 2026 |
| Rationale for combo | KRAS G12C → inactive GDP-bound state → EGFR upstream feedback loop → panitumumab (anti-EGFR) blocks re-activation loop |

**Conference catalyst:** NCT05198934 (Phase 3, CRC). OS maturation and potential FDA approval label expansion are the monitored catalysts.

**Competitive context:** Adagrasib + cetuximab (KRYSTAL-10, Phase 3) is the direct competitor — same KRAS-EGFR co-blockade rationale, anti-EGFR agent swap (pani vs cetuximab). KRYSTAL-10 also reading out 2025-2026.

---

### 3b. CRC Class Verdict
- Single-agent G12C ORR in CRC is ~10% — combination with EGFR blockade is not optional, it is the minimum viable strategy.
- KRAS G12C accounts for ~3-4% of CRC — this is a well-defined genomic niche (~4,000-5,000 new US patients/year), not a broad CRC franchise.
- The key commercial question is label timing: if CodeBreaK 300 gets FDA approval in 2026 before KRYSTAL-10, sotorasib + panitumumab takes formulary precedence.
- Pan-RAS agents (RMC-6236) do not have a near-term CRC G12C signal — this segment remains G12C-selective agent territory.

## 4. PDAC — The Hardest Tumour, The Largest KRAS Opportunity

### 4a. Adagrasib — KRYSTAL-1 PDAC Cohort
| Parameter | Data |
|---|---|
| Trial | KRYSTAL-1 NCT03785249 — PDAC cohort, Phase 2 |
| KRAS prevalence | ~85-90% of PDAC has KRAS mutation; ~2% are G12C specifically |
| Key PDAC result | ORR 6.6% (single agent); DCR ~81% — activity confirmed but modest |
| Combination strategy | Adagrasib + SOS1 inhibitor (BI 1701963) Phase 1; adagrasib + KRASG12Di (G12D inhibitor) explored pre-clinically |
| Limitation | PDAC stroma, immunosuppressive TME, and rapid development of resistance limit G12C-only approach |

PDAC KRAS G12C is a narrow slice. The real PDAC opportunity is G12D (38% of PDAC) and G12V (28%) — inaccessible to first-generation G12C-selective covalent agents.

### 4b. Daraxonrasib / RMC-6236 — Revolution Medicines (pan-RAS, RAS(ON) inhibitor)
| Parameter | Data |
|---|---|
| Mechanism | Non-covalent RAS(ON) multi-selective inhibitor — active against G12C, G12D, G12V, G13D in GTP-bound active state |
| Lead indication | PDAC — ~90% KRAS-driven; G12D + G12V dominant alleles |
| Key trial | RMC-6236-001 (Phase 1/2, NCT06625320 — Phase 3 in DB as of 2026); PDAC expansion cohort |
| Phase 1 PDAC signal (ASCO 2024) | ORR 23% in PDAC (heavily pre-treated, including G12D); mPFS ~5.7 mo — superior to any prior single agent in 2L+ PDAC |
| Phase 3 initiation | NCT06625320 confirmed as Phase 3 PDAC (Revolution Medicines) |
| Combo strategy | RMC-6236 + gemcitabine/nab-paclitaxel (1L PDAC); also RMC-6236 + RMC-4630 (SHP2 inhibitor) for resistance prevention |
| Safety signal | Dose-limiting toxicities include hyperglycaemia (RAS/MAPK biology in islet cells), rash, GI — manageable to date |
| Differentiation vs G12C-selective | Addresses G12D (inaccessible to sotorasib/adagrasib); broader allele coverage; potential pan-tumour label |

**Conference catalyst:** NCT06625320 Phase 3 PDAC tracked. Phase 3 design and interim OS endpoints are the watched catalyst for 2026-2027.

**Companion programme:** RMC-6291 (G12C-selective RAS(ON) inhibitor) is being developed alongside RMC-6236 as the cGVHD/NSCLC G12C asset — distinguishing the pan-RAS from the G12C-precise strategy within RevMed's portfolio.

---

### 4c. PDAC Class Verdict
- PDAC has no second-line standard of care with >10% ORR beyond olaparib in BRCA-mutant (~5-7% of PDAC). RMC-6236 at 23% ORR in a pan-KRAS unselected PDAC population is the most meaningful PDAC signal in years.
- G12C-selective agents (sotorasib, adagrasib) cannot serve the ~96% of PDAC that is not G12C — RevMed has structural first-mover advantage in the broader PDAC KRAS franchise.
- The enabling assumption for PDAC pan-RAS is therapeutic window: normal cells have WT RAS — RAS(ON) inhibition must spare WT enough to avoid unacceptable toxicity. Phase 1 data suggests manageable; Phase 3 at scale will stress-test.

## 5. Cross-Tumour Resistance Mechanisms — Class-Wide Risk

| Mechanism | G12C-selective agents | Pan-RAS |
|---|---|---|
| Secondary ON-target mutations (Y96D, H95D) | High risk — covalent binding site | Lower — non-covalent, different binding |
| Allele switching (G12C → G12D/G12V) | Loses activity | Retained |
| Upstream RTK bypass (EGFR, MET, FGFR amp) | Major (especially CRC) | Partial mitigation — all KRAS alleles still inhibited |
| Downstream bypass (NF1 loss, BRAF V600E) | Full escape | Full escape — same vulnerability |
| EMT / histological transformation | Full escape | Full escape |

Key implication: combination strategies (KRAS-i + SHP2-i, KRAS-i + EGFR-i, KRAS-i + MEK-i) are class-level requirements, not optional add-ons. The asset that cracks durable combination tolerability in the relevant tumour context wins the franchise.

## 9. Synthesis: Class Trajectory Vector

```
G12C (covalent) ──────────── Combination era ──────→ Resistance biology defines winners
                             (EGFR-i, ICI, SHP2-i)

G12D / pan-RAS ──────────── De novo access to      ──────→ Therapeutic window + PDAC OS
(non-covalent RAS-ON)        90% KRAS PDAC                   = registration readout 2027-28
```

The class is not converging — it is diverging. G12C agents fight a differentiated combination battle in NSCLC and an approval-timing battle in CRC. Pan-RAS / G12D agents are writing a new chapter in PDAC where no prior drug class has meaningfully worked. The risk profiles are different: G12C risks are clinical (resistance, combo tolerability); pan-RAS risks are biological (therapeutic window vs WT RAS).

The most underappreciated dynamic: **allele switching** as a resistance mechanism to G12C agents creates a patient population (post-G12C treatment, now G12D/G12V dominant clone) that is the natural 2L population for pan-RAS agents. RMC-6236's Phase 3 design would be strengthened if it enrolled post-G12C-inhibitor PDAC — a real-world bridging of the two generation of agents.
